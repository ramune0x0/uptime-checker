# 標準ライブラリまとめ

ステップで使った関数を pkg.go.dev を見ながら自分の言葉で書く。項目は 4 つ。

- **シグネチャ**: 引数と戻り値の型をそのまま写す
- **何をするか**: 1〜2 文
- **エラー**: どんなときにエラーになるか。エラーの型。エラーにならないケースも書く
- **自分のコードでの使い方**: どのファイルのどこで、何のために呼んでいるか
