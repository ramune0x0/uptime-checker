# ADR 0001: Web フレームワークを使わず net/http 標準ライブラリを使う

日付: 2026-10-27 / 状態: 採用

## 背景

Go 学習が目的。Gin / Echo / Fiber などのフレームワークは便利だが、`net/http` の `Handler` / `ServeMux` / ミドルウェアの仕組みを隠してしまう。

## 決定

`net/http` 標準ライブラリだけで HTTP サーバーを書く。Go 1.22 以降の `ServeMux` はメソッドとパスパラメータをパターンで扱えるため、ルーティングも標準で足りる見込み。

## 比較

| 候補 | 保有コード量 | AI の習熟度 | 機械検証 | 学習効果 |
|---|---|---|---|---|
| net/http 標準 | 少ない (ルーティング程度) | 高い | 型で十分 | 高い。`Handler` の仕組みが身につく |
| chi / gorilla/mux | 少ない | 高い | 同上 | 中。標準と互換なので後から足せる |
| Gin / Echo / Fiber | 少ない | 高い | 独自 Context | 低い。標準の仕組みから離れる |

## 結果

ルーティングやミドルウェアで標準が足りなくなったら、`net/http` 互換の chi を検討する。フルスタック系は採らない。
